# Задание для первого вклада Claude

Прочитай текущие решения и предложи собственную публичную методику в editors/claude/method.md через отдельный pull request. Эта страница — задание; она не содержит материала, написанного Claude.

Разбери три типичных проблемы: одинаково точные, но эмоционально разные дубли; перебивка, которая опаздывает к указательному слову; пауза, которая кажется длинной по тексту и убедительной при просмотре. Для каждой дай условия, два возможных монтажа, пользу каждого, конкретную ошибку, точку проверки и критерий выбора. Отмечай учебные примеры. При разногласии с существующей методикой сохраняй обе позиции и опиши A/B-проверку. Указывай модель и какие медиа действительно были доступны. Не включай чужие исходники, закрытые инструкции или частные диалоги.

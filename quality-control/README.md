# Независимая приёмка
Hard gates: корректность фактов, согласия/права, отсутствие раскрытия личных данных, декодируемость, обязательные delivery specs, отсутствие незакрытых P0/P1. Unknown по обязательному gate блокирует статус approved.
Рубрика 0–5 на каждую ось: story 25%, rhythm 15%, picture 15%, sound 20%, graphics 10%, style 10%, delivery 5%. 0 отсутствует/вредит, 1 существенные дефекты, 2 слабое исполнение, 3 функционально, 4 профессионально, 5 исключительно убедительно на конкретном материале. Каждый балл с таймкодом/наблюдением. Не ставить балл за недоступную модальность. Вес — начальная настройка, не универсальный стандарт. Порог по умолчанию 4/5, не замена hard gates.
Критик получает экспорт, brief, спецификацию, исходники для фактчека, но не самооценку исполнителя. Отдельно: декод/метаданные; слух; зрение; normal playback; спорные границы; проверка текста, лицензий; устройство. Для фото/VR/HDR использовать соответствующий метод. Если критик имеет только кадры, это частичная проверка.
Отчёт: artifact SHA256, version, observed modalities, evidence, gates (pass/fail/unknown), scores, defects {severity, start_frame, end_frame, symptom, evidence, proposed_fix}, limitations. После патча новый SHA, повторное наблюдение, не переносить старый pass на изменённый файл.

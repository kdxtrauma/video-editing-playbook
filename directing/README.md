# Режиссёрская мастерская
Монтаж управляет не количеством событий, а доступом зрителя к смыслу. Для каждого эпизода ответить: кто чего хочет? что изменилось? кто знает больше? что зритель должен заметить до/после? какой план даёт лучший доступ? что будет при удалении?
## Режиссёрские стратегии
- Наблюдение: длительность жеста, естественная атмосфера, редкие склейки. При конфликте важнее непрерывность доказательства, чем эффект.
- Субъективность: направление взгляда → предмет → реакция; звук может предшествовать изображению. Не подменять реакцию чужим временем.
- Контраст: ожидание/реальность, тишина/действие, общий/деталь. Контраст строится из реального отличия, не из случайной вспышки.
- Сжатие: сохранить состояние до, решающий шаг и состояние после; пропуски не создают ложную причинность.
- Объяснение: тезис → демонстрация → проверка → ограничение. Не показывать иллюстрацию, противоречащую сказанному.
- Саспенс: определить информационную асимметрию; отложить раскрытие до момента максимального смысла, а не до искусственного таймера.
- Комедия: удержать ожидание, открыть нарушение, дать реакцию; сравнить разные длительности паузы.
## Практика выбора дубля
Оценить точность смысла, естественность интонации, взгляд, непрерывность, техническую пригодность. Смысл — hard gate. Сильный дубль с исправимым шумом предпочтительнее чистого пустого дубля, если восстановление реально. Сравнить в контексте соседних кадров.
## Пульс сцены
Разметить смысловые акценты и прослушать без изображения. Режь при изменении информации, завершении жеста, смене внимания или намеренном нарушении ожидания. Длинный план оправдан если событие развивается внутри кадра; короткий — если зритель успевает распознать объект. Не устанавливать universal shot length.
## Творческое испытание
Для одного ключевого beat сделать две версии: ведущий → деталь → реакция и непрерывный план. Сравнить на одинаковом звуковом уровне: понимание, эмоциональный эффект, естественность. Если нет разницы, выбрать более простую. Для референса переносить грамматику, не чужие узнаваемые активы.

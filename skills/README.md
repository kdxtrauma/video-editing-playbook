# Каталог навыков
101 оригинальных операционных карточек в 20 дисциплинах. Целевой backlog: 2210 карточек (арифметическое исправление прежней суммы 2130). Не считать backlog выполненным. Каждый skill содержит триггер, процедуру, запрет, критерий приёмки, упражнение, ссылку на теорию и исполнительный интерфейс; это не 101 отдельных готовых плагинов.
Поиск: сначала жанр и beat, затем discipline + when, выбрать ограниченный набор. Карточки не требуют применения всех эффектов. Новая карточка должна добавлять независимую технику/условие, проверяемый пример, negative case и подтверждённый способ выполнения. Не генерировать тысячи косметических перефразировок.

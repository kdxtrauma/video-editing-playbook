# Каталог навыков v2
207 основных операционных карточек в 20 дисциплинах, включая 106 новых техник. [Контекстная лаборатория](labs/README.md) — 2003 практических сценариев, сформированных из комбинаций техники, жанра и производственного ограничения. Всего 2210 учебных единиц; не 2210 независимых техник. Учебные сценарии требуют проверки применимости и практического исполнения, не являются готовыми видео или прошедшими экзаменами. Исходные 101 карточка сохранены.
Каждый базовый навык: триггер, процедура, запрет, критерий приёмки, упражнение, ссылка на теорию и интерфейс исполнения. Подбирай по реальной задаче, не применяй всё подряд. Новые базовые техники должны быть содержательно отличимы; комбинации хранить отдельно в labs/.

# Контекстная лаборатория
2003 учебных сценариев, автоматически составленных из 207 исходных профессиональных карточек, 25 жанров и шести ограничений. Это разные условия практического выбора, а не 2003 независимых техник и не готовые смонтированные видео. Сумма core + labs = 2210 учебных единиц. Каждая комбинация skill/genre/constraint уникальна в дисциплине. Применимость не гарантируется: сначала доказать триггер навыка на реальном материале; отказ от ненужного эффекта является правильным ответом. Для узкого навыка и неподходящей сцены обязательна маркировка not applicable.
Рекомендуемый цикл: выбрать жанр, реальное ограничение и дисциплину, получить 3–8 релевантных сценариев, проверить применимость, выполнить A/B, записать доказательства. Не использовать как обучающую истину без проверки. Не считать автоматически сгенерированный тест пройденным. Индекс: index.json.

# Деревья решений
## Склейка
Изменилось знание/цель/взгляд/движение? Нет → держать, если план живёт; если мёртвый — уплотнить паузу без ущерба интонации. Да → проверить материал соседнего плана. Нужна непрерывность действия → cut on action с совпадением фазы; нужен смысл → реакция/деталь; нужна связь пространств → establishing или sound bridge. Проверить на обычной скорости.
## B-roll
Есть конкретная функция? Нет → не вставлять. Есть доказательство? → реальный соответствующий кадр с provenance. Нет → иллюстрация/схема с маркировкой, или оставить лицо. Есть достаточный hold и безопасная компоновка? Нет → другой кадр/кадрирование, не ускорять до неузнаваемости. Вход до слова если надо подготовить объект, на слове если раскрытие, после если реакция. Выход когда функция выполнена.
## Переход
Изменение места/времени/состояния? Нет → обычная склейка часто лучше. Есть визуальная связь? → match cut. Есть общий физический объект/движение? → wipe/whip только при согласованном направлении. Иначе cut, dissolve для мотивированного времени/состояния, J/L для звуковой связи. Нет handles → не использовать dissolve.
## Звук
Речь непонятна? → проверить источник, клиппинг, шум, конкуренцию частот; сначала clip gain, затем умеренная обработка, automation музыки; при повреждённом источнике альтернативный дубль. Действие звучит пусто? → Foley с реальным материалом/дистанцией; room tone между склейками. Сравнить без/с эффектом.
## Графика
Можно понять из кадра? Да → не дублировать, кроме доступности/требования. Нет → определить ровно одну информационную задачу; простая подпись, стрелка, схема или анимация. Проверить движение, contrast, время чтения, safe zone на устройстве.
## Цвет
Известны input color space и delivery? Нет → сначала выяснить; не угадывать LUT. Да → нормализовать, exposure/WB, match, творческий look, output transform, scopes. Проверить skin/material colors и уровни по спецификации.
## Критика
P0/P1? → fix, rerender, independent recheck. P2? → исправить если улучшение подтверждено и лимит позволяет. Неясно? → A/B одной переменной. Недоступно наблюдение? → unknown, не pass.

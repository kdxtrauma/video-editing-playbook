# FFmpeg V1: реальное исполнение
ffmpeg_executor.py — адаптер для engines/pipeline.py, не универсальный монтажёр. Поддерживает несколько нормализованных CFR исходников с аудио, прямые склейки, fit/pad без обрезки и H.264/AAC master. Проверяет реальные границы источников, decoded PTS, отсутствие начального AV offset, число кадров выхода, размеры и FPS. Отказывается от неописанных дорожек, переходов, ретайма и specialist advice вместо имитации исполнения. Цвет, сложная графика, независимый B-roll, Foley, HDR, звук без исходного аудио — через другие адаптеры.
Конфиг executor: ["/absolute/python", "/absolute/repo/engines/ffmpeg_executor.py"]. Brief: sources (инвентаризация), source_paths (доверенная карта asset_id → локальный абсолютный файл), width, height. Не разрешать модели подменять source_paths. Оператор сам проверяет права, цветовое пространство, спецификацию поставки и необходимость согласия на медиа. Нормализовать HDR/LOG/нестандартные звуковые форматы до использования; этот адаптер не делает color management.
Версии требуют отдельного каталога, промежуточные lossless сегменты сохраняются; для больших проектов нужны контроль диска и специализированный NLE. Проверка: python -m unittest discover -s engines/tests -v. Интеграционный тест создаёт два синтетических клипа, рендерит 50 кадров и декодирует мастер. Это тест технического исполнения, не оценка художественного качества.

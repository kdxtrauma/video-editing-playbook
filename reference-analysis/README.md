# Анализ референса
Только доступный материал и разрешённое использование. Не скачивать с обходом ограничений, не копировать чужую музыку/графику/личность без прав. Извлекать переносимые принципы.
1. Инвентаризация: длительность, aspect, FPS, доступный звук и видео. Зафиксировать, что реально просмотрено.
2. Shot log: интервалы кадров, вид склейки, размер плана, движение, объект внимания, экранный текст, звуковое событие, смысл beat. Отдельно uncertainty.
3. Ритм: распределение длительности кадров по сценам, паузы, моменты ускорения; не сводить всё к среднему ASL. Сопоставить звук и визуальный контакт.
4. Визуальный язык: композиция, цвет/контраст, мотив, глубина, движение, типографика. Не угадывать исходную камеру/LUT.
5. Перенос: таблица observed feature → функция → эквивалент на новых исходниках → риск → тест. При отсутствии нужного плана выбрать альтернативу той же функции.
6. Сначала проба 10–20 секунд подходящей сцены (не жёсткий лимит); потом full rough. Сравнение по функции, а не пиксельной идентичности.
Пример: референс открывает механизм до ключевого слова, звук контакта совпадает с фактическим движением, возвращение на лицо в момент вывода. В новом видео применить подготовку объекта, точный звук и реакцию; не заимствовать чужой клип.

# Продюсерская система
До монтажа заполнить brief: audience, desired_change, platform, format, length constraints, source inventory, allowed assets, privacy, brand, mandatory elements, deliverables, deadline, cost limit. Определить success criteria по результату зрителя, не количеству эффектов.
Матрица решений: обязательное/желательное/делегированное. Не менять обязательное; для желательного указать tradeoff; делегированное решать самостоятельно. Для одного материала планировать master и производные отдельно (не автоматически кропать).
Ресурсные уровни: A — исходники и доступный монтаж; B — добавление лицензированного B-roll, графики, sound design; C — дополнительные съёмки/CG/генерация при реальном доступе и согласии. Сначала определить минимально достаточный уровень, затем улучшать наиболее заметные слабые места. Не тратить бюджет на эффект без вклада.
Риск-регистр: source ID, риск, вероятность/последствие, способ уменьшения, ответственный, статус. Hard gates: конфиденциальность, права, достоверность, срок, обязательная спецификация.
Пакет сдачи: версии, проект, исходный/выходной таймбейс, мастер, производные, captions, assets/license manifest, QC report и known limitations. Не обещать охваты и удержание без реальных аналитических данных.

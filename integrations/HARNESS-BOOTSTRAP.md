# Установка в DeepSeek Harness: техническое задание для локального агента
Ты имеешь доступ к локальному исходному коду Harness и уже настроенным моделям. Эта инструкция не предполагает замену приложения. До изменений создай отдельную ветку/резерв, исследуй реальную архитектуру (router, tools, system instructions, memory, callbacks, media access). Не публикуй ключи и локальные медиа.
1. Закрепи git commit video-editing-playbook. Прочитай AGENTS.md, academy/README.md, engines/protocol.md, engines/layered-executor.md. Запусти python -m unittest discover -s engines/tests -v. При failure исправь причину, приложи фактический лог. Не пропускай тесты ради формального pass.
2. Найди реальные интерфейсы GPT/Claude/DeepSeek, не создавай выдуманный API. Настрой независимые контексты director_a и director_b; judge получает обезличенные концепции. Сделай два настоящих коротких вызова и проверь JSON, usage, ограничения модели. Если встроенные инструменты лучше, адаптируй их к stdin/stdout протоколу. При необходимости integrations/model_gateway.py — только текстовые роли.
3. Встрой в существующий lifecycle stages capabilities, observe, producer, director_a, director_b, judge, editor, executor, critic, repair. Подключи engines/pipeline.py либо его контракт, не подменяя существующую orchestration. Выбери plan_format=cut-v1 или layered-v2, либо напиши проверяемый NLE-adapter. Дай editor реальную схему, ограничения и доступные ассеты. Модели не могут сами менять operator config и пути.
4. Реальное наблюдение: инвентаризация медиа, timecode, речь, кадры и движение, звук. Проверь модальности каждой модели: кадры или transcript не означают просмотр всего видео. Независимый критик должен иметь фактический мастер, AV evidence и исходники. Если полного review нет — статус blocked/partial, не approved.
5. Вычисляй budget по входным/выходным токенам и стоимости каждого вызова, а не только числу запросов. Зафиксируй hard caps, timeouts, stop conditions, checkpoint и last-known artifact. Не трать 2 млрд токенов автоматически.
6. Выполни synthetic end-to-end smoke: два разных цвета/звука, перебивка, титр, cue, экспорт, hash, decode, проверка на frame boundaries и длительность. Затем негативные cases: неверная лицензия, отсутствующий ассет, неподдерживаемый transition, расхождение hash, P1, отсутствие наблюдения. Все обязаны остановить approved.
7. Реальный бенчмарк на разрешённом видео: прежняя система и новая, тот же бриф/исходники/ресурсы. Зафиксируй число вмешательств автора, качество независимого просмотра, затраты, ошибки. Не объявляй преимущество без результата. После проверки активируй режим по умолчанию только для поддерживаемых задач.
8. Отчёт локального агента: какие файлы Harness изменены, какие адаптеры реально связаны, версии, тесты, путь к реальному экспорту, какие операции всё ещё blocked. Запиши verified feedback в private memory. Публичная база — только обобщённые методики.
Запуск эталонного контура: python engines/pipeline.py --config /private/config.json --brief /private/brief.json --work /private/new-run. Config — operator-owned, абсолютные команды адаптеров; роли описаны в engines/protocol.md. Никаких секретов в репозитории.

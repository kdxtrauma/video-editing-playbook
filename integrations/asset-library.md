# Библиотека B-roll, музыки и SFX
Оператор формирует приватный manifest JSON array: {id,kind,subject,action,context,description,tags,material,perspective,rights,license,source_url,local_path,duration}. rights=cleared только после реальной проверки использования, территории, срока, атрибуции и коммерческих условий. Публичный репозиторий не содержит чужие файлы. asset_search.py предлагает кандидатов из одобренной библиотеки по лексическому совпадению; не утверждает, что кадр просмотрен или звук подходит. Модель уточняет запрос по функции, выбирает только после наблюдения, фиксирует ID, точный тайминг, происхождение и альтернативу. Для Foley описывать материал, контакт, силу, дистанцию, акустику; для музыки — драматургическую функцию и фразу. Для B-roll — предмет, действие, видимый результат, условия, ракурс и допустимый контекст. Сохранять локальные метаданные и файлы в доверенном brief.layer_assets. Если кандидат не подходит, не вставлять его ради наличия.
Пример: python integrations/asset_search.py /private/manifest.json "metal latch closes closeup" --kind video

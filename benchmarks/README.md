# Экзамены
cases.json — 20 сценариев проектирования и диагностики, не готовые видеофайлы и не результаты экзамена. Для каждого создать/получить разрешённую тестовую сцену, сохранить скрытый эталон дефекта, дать агенту brief и исходники, сравнить baseline и новую систему на одинаковых ресурсах. Проверять независимым критиком и человеком, фиксировать время/токены/число вмешательств/дефекты. Не выбирать победителя по самооценке.
Целевые метрики: доля выпусков без P0/P1, количество вмешательств автора, процент реально проверенных операций, качество слепого A/B, стоимость/время. Сначала тестировать 3–5 коротких сцен, затем 25 жанров. Не заявлять статистическую значимость без выборки.

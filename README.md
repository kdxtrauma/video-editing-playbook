# База монтажа разговорного видео

Открытая рабочая методика для редактора подкастов, интервью и вертикальных нарезок. Здесь хранятся наблюдаемые критерии решений, учебные примеры и код. Запись собственного материала, его просмотр и правка таймлайна происходят в локальном монтажном проекте.

## С чего начать

1. Прочитайте [практику режиссуры](editors/chatgpt/directing.md) и [учебные задачи](examples/cuts.md).
2. Откройте копию таймлайна. Зафиксируйте, какие каналы доступны агенту: звук, видео в движении, отдельные кадры, текст. Таймкод подкрепляет решение только в пределах изученного материала.
3. Сохраните монтажный лист до сборки. После сборки сравните его с новым экспортом из редактора. Просмотрите MP4 вне редактора.
4. Для дополнений Claude используйте [задание](editors/claude/README.md). Указывайте авторство и версию модели, если они известны. Подтверждённые авторские предпочтения действуют в пределах указанного формата.

## Код

Python 3.9+, FFmpeg и ffprobe. Команды запускаются из корня репозитория. Медиа, транскрипты, API-ключи и результаты работы держите вне публичной копии.

    python tools/podcast_edit_engine.py render source.mp4 work/rough --plan work/plan.json
    python tools/podcast_director.py audit work/plan.json work/from-resolve.fcpxml

Каталог результата render должен быть новым. Для первой команды нужны существующий файл и план в формате examples/plan.json. Замените имя исходника, FPS и границы на реальные значения. Команда создаёт rough.mp4 и rough.fcpxml. Импортируйте XML в Resolve, затем независимо экспортируйте фактический таймлайн в from-resolve.fcpxml для второй команды. Сверка XML, созданного самим render, проверяет только согласованность файлов.

Необязательный режим advise описан в справке python tools/podcast_edit_engine.py advise --help. При его запуске Claude и OpenAI получают текст и до шести кадров, DeepSeek — текст и два разбора. Используйте этот режим только с разрешёнными к передаче материалами и доступом к API. Рабочая область render — один SDR-клип с постоянным FPS и звуком, прямые склейки. Сложные дорожки, графику, сведение и цвет проверяют в Resolve и по финальному экспорту.
